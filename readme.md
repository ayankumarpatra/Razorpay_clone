# Razorpay Landing Page Clone

A frontend recreation of the Razorpay landing page, built as a learning project using HTML and Tailwind CSS.

## Tech Stack
- HTML5
- Tailwind CSS
- Custom CSS (used once only for animations)

## Features
- Responsive landing page layout
- Hero section
- Payment product cards
- Business banking section
- Product features
- Customer testimonials
- Call-to-action section
- Footer

## What I Learned
- Tailwind CSS utility classes
- Flexbox and CSS Grid
- Positioning and layout techniques
- Background images and SVGs
- Hover effects and transitions
- Responsive design

## Disclaimer
This is an unofficial educational frontend recreation. It is not affiliated with or endorsed by Razorpay.
